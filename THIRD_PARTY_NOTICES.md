## Binary bundles only

A packaged `AntennaFox.app` additionally contains native libraries that come with the interpreter and the wheels,
either as separate files or linked into `libpython`: OpenSSL 3 (Apache-2.0), zlib (Zlib), bzip2 (bzip2-1.0.6),
xz/liblzma (0BSD), libffi (MIT), Expat (MIT), SQLite (public domain), mpdecimal (BSD-2-Clause), and the SciPy and
Pillow libraries listed above. The exact set depends
on the interpreter used for the build and is recorded per build in `BUNDLE_INVENTORY.md`; the build fails if a
library of unknown origin, a GPL-only Qt module or GNU Readline is found.

The bundle is produced with [PyInstaller](https://pyinstaller.org) (GPL-2.0-or-later with the Bootloader
Exception; the exception permits distributing bundled applications under any license, and no notice is required).

## LibreVNA

[LibreVNA](https://github.com/jankae/LibreVNA) and LibreVNA-GUI are separate projects licensed under GPL-3.0.
AntennaFox contains no LibreVNA source code or binaries. It communicates with an independently installed
LibreVNA-GUI over the documented SCPI/TCP interface described in the LibreVNA programming guide. The emulated SCPI
server in `src/antennafox/instrument/librevna/emulator.py` is an independent implementation of the documented protocol
behaviour for testing purposes. "LibreVNA" is used only to describe compatibility; no affiliation or endorsement is
implied.
